# 终端链接与主界面整理

研究日期：2026-10-08。

参考 [OSC 8 提案](https://gist.github.com/egmontkob/eb114294efbcd5adb1944c9f3cb5feda)。OSC 8 改变之后绘制单元格的链接属性，URI 为空时关闭链接；不等于从可见文字猜测 URI。使用当前固定 Termux 源码，新增小范围补丁，详见 `third-party/termux/README.md`。

## 交互

- 普通终端点按 HTTP/HTTPS URL 或 OSC 8 标签，先展示真实目标，用户选择打开、复制或选择终端文本。
- 启用鼠标的 TUI 保留点击事件，长按查看链接；长按抬手不额外发送远端点击。
- 非链接的滚动、长按选区、中键粘贴沿用已有行为。
- 只允许用户确认后使用 ACTION_VIEW 打开 HTTP/HTTPS；其他 OSC 8 目标仅可查看、复制。远端 file URI 不会解析成手机本地文件。
- 没有自动抓取标题、favicon、预览，也不在输出更新或绘制时扫描链接。

## 状态与边界

链接元数据与网格一同移动，覆盖和擦除会清除旧目标；测试覆盖宽字符、组合字符、复制／插入／删除、滚动、主辅屏和缩放重排。目标缓存有上限，过旧目标淘汰后不能通过 OSC 8 标签打开；不会错误指向后续目标。无鼠标 hover 分组，忽略 `id` 参数。

普通 URL 检测仅合并自动换行，不跨显式换行拼接。单次最多读取 64 行、8,192 UTF-16 字符，避免长输出导致点击阻塞。仅识别带 http:// 或 https:// 的地址。

手机浏览器访问 localhost 指向手机，不会自动改写为远端服务器；可使用已有本地端口转发访问远端服务。

## 主界面

统一服务器、会话与设置的圆角分组、色彩和留白；搜索框增加图标，空列表／无匹配结果有明确说明。会话仍显示主机名、数字编号、远端标题或状态，增加连接中／待确认／待认证／已连接／已断开文字标识。无新增状态轮询和旋转动画。保持现有排序、收藏、菜单和关闭确认。

## 发布时间

今后的 APK、Release 标题／说明和 build-info.json 共用一次生成的 `YYYY-MM-DD HH:mm:ss UTC+8`，由 `TZ=Asia/Shanghai date` 生成。Gradle 和发布元数据校验拒绝旧 UTC 或其他偏移格式；历史 Release 不改写。

## 本轮验证

- Debug 编译与 lint 通过；153 项终端核心测试（含 4 项 OSC 8 用例）通过，URI 校验单元测试通过。
- Android 15 模拟器：6 项链接、触摸、粘贴与管理页面测试通过；使用临时公钥认证 SSH 服务的会话导航测试通过。已检查主机列表与链接弹窗截图。
- 4 项发布校验测试及 Termux 补丁完整性校验通过。实际设备的浏览器跳转和不同 TUI 生成的 OSC 8 标签仍建议日常使用复测；模拟器通过不代表已覆盖所有设备。
