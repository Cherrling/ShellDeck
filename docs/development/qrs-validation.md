# QRS 本地验证

验证环境：JDK 17、Android API 35 本地模拟器；源码同步至 `/dev/shm` 构建。本轮未推送、未触发 Release，也未改变版本号。

- `:app:lintDebug`、`:app:assembleDebug`、`:app:assembleDebugAndroidTest` 通过。
- App JVM：54 项中 43 项执行通过（含 7 项 QRS），11 项依赖临时 SSH 服务的测试跳过；本轮未改 SSH transport，未启动该测试服务。
- 设备：3 项 QRS 测试通过；既有备份 Repository 的 4 项回归通过。另在 1280×800、160 dpi 的横屏平板尺寸下复测发送界面、每次默认加密与旋转/取消，1 项通过。
- 图像链路测试使用临时生成的测试私钥，只在内存生成二维码位图，经过 ZXing 普通图像定位和解码后走真实备份恢复逻辑。测试验证源 vault 不能解开目标 vault 的密文，以及预览前数据库不产生记录。
- 初次图像测试因单帧 FormatException 失败。独立 JVM 合成码测试在 100 帧中也出现 1 帧定位失败；实际接收逻辑本来就会跳过无法识别的帧。设备测试改为模拟同样行为，并同时限制漏识别比例和要求完整收齐；重新运行后通过，没有使用 PURE_BARCODE 绕过普通定位。
- 官方固定 commit 的 raw / zlib 测试向量通过。发送单块字节与上游逐字节一致，向量同时由官方 decoder 验证；损坏数据与解压输出超限会被拒绝。
- APK 内容检查确认 ZXing LICENSE / NOTICE 已打包，位于 main assets，正常版与精简版共用。

尚未完成两台真机对扫与功耗实测。摄像头对焦、不同分辨率/亮度、真实锁屏和厂商权限行为仍需真机验收。模拟器上的图像识别与界面通过不代表这些条件已验证。
